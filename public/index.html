BRING YOUR OWN ASSISTANT

Your AI knows context.
You choose what to share.

Vennith never connects to your conversation history. Ask an MCP-compatible assistant to prepare a minimal profile, review every field, then approve it.

  1. Add this site's as a custom remote MCP server in a client that supports Streamable HTTP.
  2. Ask for get_profile_schema. Draft only attributes you authorize.
  3. Review and correct the card. Explicitly approve it before any comparison or match call.
  4. Use get_personality_archetype, compare_compatibility, or find_compatible_matches.

ChatGPT: Settings → Apps → developer mode, if available for your plan and workspace → create a custom app using the MCP URL. Claude: Settings → Connectors → add a custom connector using the MCP URL, if available. Menu names and custom-connector access depend on your client and administrator.

These are generic MCP connections, not native account integrations with ChatGPT, Claude, Gemini, or Grok. No OAuth, passwords, or history access. A local HTTP endpoint needs a supported local client or an authorized HTTPS deployment for remote clients.
